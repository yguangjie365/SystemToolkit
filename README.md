# SystemToolkit

> 让 Windows 重装，不再从零开始。

面向 Windows 10 / 11 的综合系统维护与环境恢复工具。不是"Windows 小工具集合"，而是一套把**驱动 / 软件 / 网络 / 配置 / 数据**保存下来、在系统重装后完整恢复的工作环境平台。

> 📌 **项目性质声明**：本项目为**个人爱好与自用需求驱动的非商业项目**，不以任何形式盈利，将开源发布到 GitHub，并在应用 About 中说明所借鉴与引用的开源项目。
> 该性质直接影响第三方代码引入策略，详见 [ADR-002](Docs/decisions/ADR-002-驱动中心技术来源与第三方代码引入规范.md)；许可证变更（MIT → GPL-3.0）见 [ADR-004](Docs/decisions/ADR-004-开源许可证变更MIT转GPL-3.0.md)。

## 核心理念

```text
正常使用 → 保存 Windows 工作环境 → 重装 Windows → 导入恢复包 → 回到原来的工作环境
```

三个关键词：**维护、恢复、效率**。

- **维护** —— 硬件状态、网络状态、软件、驱动、系统配置
- **恢复** —— 驱动、软件、网络、工具配置、用户数据、备份快照
- **效率** —— 批量安装、批量恢复、网络诊断、局域网传文件、自动备份、系统报告

## 权限模型

**主程序默认标准权限运行，不整体提权。**

```text
SystemToolkit.exe            （标准权限）
        │
        ├── 普通权限功能
        └── ElevatedHelper.exe  （按需 UAC 提权）
               ├── 驱动操作
               ├── 网络修改
               ├── 系统修复
               └── 其他特权任务
```

提供"以管理员身份重启"入口作为可选增强；即便在管理员模式下，特权操作仍统一走 Elevated Helper 通道，保证代码路径与日志一致。

> 注意：这与旧工程 `app.manifest` 声明 `requireAdministrator` 的做法**相反**，是本次重写的明确变更。
